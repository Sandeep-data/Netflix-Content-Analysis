# 🎬 Netflix Content Analysis Dashboard

## 📖 About the Project

This project is an end-to-end **Netflix Content Analysis Dashboard**
created using **Excel, SQL, Python, and Power BI**.

The main goal of this project was to understand Netflix's content
library by cleaning the data, analyzing it, and building an interactive
dashboard that provides useful business insights.

This project follows a complete Data Analytics workflow, starting from
raw data to final visualization.

## 🎯 Key Insights

-   Movies are available in larger numbers than TV Shows.
-   Drama is one of the most popular genres.
-   The United States has the highest number of Netflix titles.
-   Netflix content has increased significantly over the last few years.
-   TV-MA is the most common content rating.
